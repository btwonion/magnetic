# NeoForge Access Transformer Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent Magnetic's generated NeoForge JARs from containing malformed access-transformer field directives.

**Architecture:** Remove the obsolete `Inventory.items` access request at its shared class-tweaker source. Add a NeoForge-only Gradle verification task that checks the generated `META-INF/accesstransformer.cfg` token shape and wire it into each NeoForge target's `check` lifecycle.

**Tech Stack:** Gradle 9.6.1, Kotlin Gradle DSL, Modstitch 0.8.4, NeoForge ModDevGradle, Stonecutter.

## Global Constraints

- Keep the shared Fabric and NeoForge class-tweaker source.
- Keep the `RegistryLoadTask$PendingRegistration` access request.
- Do not patch or post-process generated Modstitch output.
- Do not add loader-specific class-tweaker files.
- Do not change gameplay behavior, mixins, mappings, dependencies, or supported Minecraft versions.

### Task 1: Validate Generated NeoForge Access Transformers

**Files:**
- Modify: `mod/build.gradle.kts`
- Modify: `mod/src/main/resources/magnetic.classtweaker`

**Interfaces:**
- Consumes: `build/resources/main/META-INF/accesstransformer.cfg`, generated by `processResources`.
- Produces: a `validateAccessTransformerSyntax` task on every NeoForge version project; each project's `check` task depends on it.

- [ ] **Step 1: Add the failing generated-output validation**

In `mod/build.gradle.kts`, add this NeoForge-only task after the existing
`processResources` configuration:

```kotlin
if (!isFabric) {
    val validateAccessTransformerSyntax = tasks.register("validateAccessTransformerSyntax") {
        group = "verification"
        description = "Validates the generated NeoForge access transformer syntax."
        dependsOn("processResources")

        val accessTransformer = layout.buildDirectory.file(
            "resources/main/META-INF/accesstransformer.cfg"
        )
        inputs.file(accessTransformer)

        doLast {
            accessTransformer.get().asFile.useLines { lines ->
                lines.forEachIndexed { index, rawLine ->
                    val directive = rawLine.substringBefore('#').trim()
                    if (directive.isEmpty()) return@forEachIndexed

                    val parts = directive.split(Regex("\\s+"))
                    check(parts.size in 2..3) {
                        "Invalid access transformer at line ${index + 1}: " +
                            "expected 2 or 3 tokens, found ${parts.size}: $directive"
                    }
                }
            }
        }
    }

    tasks.named("check") {
        dependsOn(validateAccessTransformerSyntax)
    }
}
```

- [ ] **Step 2: Run the validator and confirm the regression is reproduced**

Run:

```bash
./gradlew :mod:1.21.1-neoforge:validateAccessTransformerSyntax
```

Expected: `FAILED` with an error containing:

```text
Invalid access transformer at line 1: expected 2 or 3 tokens, found 4
```

The failure must identify:

```text
public net.minecraft.world.entity.player.Inventory items Lnet/minecraft/core/NonNullList;
```
